# clob/ws/client.rs 阅读笔记

## OnceCell：功能、用法与场景

- 功能：提供“一次性初始化”的容器。第一次写入后只读复用，避免重复构造。
- 常用用法：
  - `get_or_init`：第一次访问时初始化，之后直接返回同一值。
  - `get_or_try_init`：初始化可返回错误；失败不写入，下次仍可重试。
- 典型场景：
  - 惰性创建昂贵资源（连接、缓存、配置、客户端等）。
  - 保证全局/共享资源只初始化一次。
  - 运行时确定但后续保持不变的值。

在 `ChannelHandles::new_lazy()` / `get_or_connect()` 中，OnceCell 用于延迟建立连接，只有在首次订阅时才初始化 WebSocket 资源，减少空闲连接开销。
