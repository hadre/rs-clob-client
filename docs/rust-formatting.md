# Rust 格式化：Debug vs Display

## 核心区别

- **Debug（`{:?}` 或 `?`）**：用于开发/调试，尽量展示内部结构，适合容器、结构体等。
- **Display（`{}` 或 `%`）**：用于用户可读输出，强调简洁、可读、语义化。

## 常见表现

- `Debug` 通常会显示字段名、结构体层级或集合结构。
- `Display` 由类型作者自定义，可能是更短更“人类化”的字符串。

## 在 tracing 中的写法

- `?value` 等同于 `value = ?value`，使用 **Debug**。
- `%value` 等同于 `value = %value`，使用 **Display**。

## 选择建议

- 排查问题、打印复杂数据结构：用 **Debug**。
- 输出给用户或日志需要简洁语义：用 **Display**。
